# セットアップ

0.1.1の公開イメージ（amd64／aarch64）を使用します。HAOS上でビルドする必要はありません。

1. アドオンリポジトリに `https://github.com/1hira-c/VRCX-0#codex/web-haos` を登録します。既定ブランチへ統合した場合は `#codex/web-haos` を外します（登録URLを変えると別アドオンとして扱われます）。
2. VRCX-0 Webをインストールし、開始します。
3. 初回起動ログの `VRCX-0 Web access token:` に続くトークンを控えます。
4. 「Web UIを開く」でトークンを入力します。その後、既存UIからVRChatにログインします（2FA対応）。

トークンはVRChatのパスワードとは別です。既存トークンは `/data/profile/web-access-token` に保存されます。ログを失った場合は、このファイルをバックアップから確認するか、停止中に削除して再発行してください。`web-secret-key` は削除しないでください。

データと暗号鍵は `/data/profile` に保存されます。アドオンのバックアップは停止中に取得します。復元にはデータベースと `web-secret-key` の両方が必要です。イメージ更新でVRChatのログイン情報を保持できますが、ブラウザー側のWebログインはやり直してください。

通常はポート公開が不要なIngressを使います。HTTPポートを手動で開く場合は、信頼するネットワーク内でTLSリバースプロキシを使用してください。

# 制限

Web版は単一の共有プロフィールです。複数ブラウザーは同じVRChatセッションを操作します。
PCのゲームログ監視、VRChat起動、OSC、オーバーレイ、スクリーンショット選択、ローカルファイル操作は現在未対応です。
デスクトップエージェントを後から接続する設計はリポジトリの `docs/desktop-agent.md` に記載しています。
既存VRCXフォークのデータベースをそのままこのプロフィールにコピーしないでください。Web経由の旧データ取り込みは未実装です。
